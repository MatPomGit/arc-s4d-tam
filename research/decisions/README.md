# Research and architecture decision records

Create a short record for consequential decisions that affect interpretation, reproducibility or public interfaces.

Recommended filename:

`YYYYMMDD-short-kebab-title.md`

Each record should contain:

- Status: proposed / accepted / superseded;
- Context;
- Decision;
- Scientific impact;
- Alternatives considered;
- Reproducibility impact;
- Validation required;
- Related protocol/configuration paths.

Do not use a decision record to rewrite a frozen hypothesis after observing results.
