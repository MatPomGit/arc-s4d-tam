# Contributing

The canonical contribution policy is maintained in [`CONTRIBUTING.md`](https://github.com/MatPomGit/arc-s4d-tam/blob/main/CONTRIBUTING.md).

Contributions should preserve the benchmark's reproducibility guarantees, normalized result contracts and explicit treatment of unavailable metrics. Changes affecting scientific methodology, metrics, dataset registration or experimental protocols should include corresponding documentation and tests.

For implementation details, open the canonical contribution guide in the repository.

## Documentation with Zensical

Documentation is generated by [Zensical](https://zensical.org/docs/) 0.1.0, not
Material for MkDocs. Keep editing `docs/` and the existing `mkdocs.yml`; there
is no separate `zensical.toml`. The `classic` variant preserves the existing
Material layout and the custom styles in `docs/stylesheets/extra.css`.

Use Python 3.11 or later for documentation (3.12 in GitHub Actions):

```bash
python3.12 -m venv .venv-docs
source .venv-docs/bin/activate
python -m pip install -r requirements-docs.txt
zensical build --clean --strict
zensical serve
```

The build emits `site/` for GitHub Pages. Check the home page, navigation,
search, light/dark palettes, callouts, tabs, Mermaid diagrams and custom CSS
after dependency upgrades. GitHub Actions verifies key generated HTML pages.
Do not alter the existing site URL or publish the site outside the
`.github/workflows/docs.yml` deployment workflow.

Zensical 0.1.0 uses native implementations for the configured `search`
plugin and the `zensical.extensions.emoji` handlers. Other MkDocs plugins
must be checked against [current compatibility support](https://zensical.org/docs/compatibility/mkdocs/plugins/)
before adoption.
