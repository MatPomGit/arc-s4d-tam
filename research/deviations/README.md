# Protocol deviations

A deviation record is required when execution differs from a frozen, preregistered or publication-facing procedure.

Recommended filename:

`YYYYMMDD-<study-or-run-id>-short-description.md`

Record:

- date and affected run(s);
- frozen source/protocol version;
- exact deviation;
- reason;
- whether the deviation occurred before or after outcome inspection;
- impact on confirmatory validity;
- required sensitivity analysis;
- whether affected evidence remains reportable;
- linked issue/commit/evidence bundle.

Never silently repair or omit a deviation because it makes the result less favorable.
